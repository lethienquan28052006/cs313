# Ghi chú paper D-Tracker

Tài liệu chung để cả nhóm dùng **cùng ký hiệu và cách hiểu**. Ai đọc phần nào thì điền phần đó; người thuyết trình (#1, #2) và người viết report (#7) dùng file này làm nguồn chính.

Paper: https://arxiv.org/abs/2505.00242

## Mục cần điền

| Mục | Người điền | Nội dung cần có |
|---|---|---|
| 1. Bài toán | #1 | Dữ liệu tensor (thời gian × từ khóa × địa điểm), mục tiêu: mô hình hóa + dự báo trên luồng dữ liệu; 3 tính chất paper nhắm tới (interpretable, automatic, scalable) |
| 2. Bảng ký hiệu | #3 | Mọi ký hiệu trong paper: tensor, factor từ khóa/địa điểm, lõi động học, tham số tăng trưởng và khuếch tán… |
| 3. Mô hình | #3 | Tách thành trend + seasonal + outlier; hệ phản ứng–khuếch tán sinh ra lõi trend; seasonal factor; outlier thưa |
| 4. Ước lượng tham số | #3 | Vòng lặp ALS: cập nhật từng thành phần theo thứ tự nào, giải ODE thế nào |
| 5. Streaming và regime | #4 | Cập nhật online, chọn số chiều ẩn bằng chi phí MDL, phát hiện điểm thay đổi và chuyển regime |
| 6. Thí nghiệm của paper | #4 | Dataset, baseline, metric, các kết quả chính cần tái hiện |
| 7. Điểm chưa rõ | mọi người | Chỗ paper mô tả khác code gốc, chỗ chưa hiểu → đem ra họp |
